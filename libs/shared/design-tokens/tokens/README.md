# Design token source files

This directory contains the Design Tokens Community Group (DTCG) JSON source
files:

- `primitives.tokens.json` — raw palette, spacing, typography, radius, shadow,
  and motion values; added in Step 2
- `semantic-light.tokens.json` — UI-purpose aliases for the light theme; added
  in Step 3
- `semantic-dark.tokens.json` — the same UI-purpose aliases for the dark theme;
  added in Step 3
- `components.tokens.json` — stable styling aliases for shared UI components;
  added in Step 4

Do not add application-specific token files here. This library is the shared
source of truth for shell, account, commerce, and shared UI.
